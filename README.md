# Terraformia

Terraformia — одиночная браузерная игра о создании двух обитаемых поселений на Марсе. Кампания состоит из четырёх глав; игрок управляет ровером TERRA-01, добывает ресурсы, строит модули и готовит колонии к пыльным бурям и холодным ночам.

**Играть онлайн:** https://websim.com/@spoiledjar5513270/terraformia

## Запуск

Откройте `dist/Terraformia.html` в настольном браузере и нажмите «Начать экспедицию». Файл содержит стили и скрипты, внешние зависимости не требуются. Для запуска раздельных исходников откройте `index.html` либо запустите локальный HTTP-сервер из корня репозитория.

## Управление
Клавиши WASD или стрелки перемещают ровер. Удерживайте Shift для точного хода.
Подъедьте к объекту и нажмите E или щёлкните по карточке действия над объектом.

Карточка «Текущая цель» предлагает следующий шаг. Цветной маркер и мини-карта помогают найти его: зелёный — строительство, оранжевый — руда, голубой — лёд, жёлтый — выгрузка.
Запасы склада постоянно видны в правой панели. У каждого рецепта показано, сколько деталей в наличии и сколько ещё необходимо. Для теплицы и жилого отсека в стоимость включается герметичный сектор, если нет свободного. Выберите постройку, чтобы открыть её план и увидеть необходимые шаги, либо нажмите «Показать нужный ресурс». Зелёные клетки подходят для строительства, полупрозрачный силуэт показывает будущий модуль. После постройки сектора игра продолжит вести к выбранному модулю.
Прогресс переработки и урожая показывает фактическое состояние текущего цикла и причину остановки. Esc снимает план строительства или открывает паузу. Сохранение доступно через меню паузы.

Скорость ×4 помогает дождаться переработки и зарядки. Во время прогноза и испытания действует обычная скорость.
Звуки включаются после первого действия. Их можно отключить кнопкой «Звук».

## Исходный код и проверка

- `index.html`, `style.css` — структура и оформление интерфейса.
- `engine.js` — симуляция, ресурсы, строительство и кампания.
- `guidance.js` — цели, рецепты, прогресс и подсказки.
- `render.js` — графика Canvas 2D.
- `sound.js` — звуковое сопровождение Web Audio.
- `app.js` — управление, интерфейс и сохранение.
- `tests/` — автоматические проверки.

Проверки запускаются из корня репозитория в Node.js (версия 18 или новее):

    node --test tests/*.test.js

Тесты проверяют расчёт стоимости вместе с сектором, недостаток деталей, маркеры добычи и выгрузки, доступные клетки, прогресс переработки, первую главу по рекомендациям системы, движение, ресурсы, бурю, энергоснабжение, управление Алексом, грузовые маршруты, обе ветки кампании и повтор финального испытания.
